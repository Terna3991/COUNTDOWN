# Live Launch Countdown Webpage

Open `index.html` in a browser to view the live countdown.

## Host online

Upload this folder to one of these free static hosts:
- GitHub Pages
- Netlify
- Cloudflare Pages
- Microsoft Azure Static Web Apps

After deployment, share the public URL on Facebook or add it to a Facebook Page post.

The countdown stops at November 28, 2026 at 12:00 PM and requires no server or database.
